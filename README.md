# Smoky Mountain Investor Report — Reader

This repository powers the report reader on www.scale-group.net.

## Publishing a new edition (about one minute)

1. Export the report as a **PDF**.
2. Name it with the month and year in it, for example
   `Smoky_Mountain_Investor_Report_Issue_6_November_2026.pdf`
   (any name works as long as it includes the month name and the year).
3. On github.com, open the **reports** folder in this repository.
4. Click **Add file → Upload files**, drag the PDF in, and click **Commit changes**.

That's it. Within about a minute:
- the main Investor Report page shows it as the current edition, and
- the archive lists it first with the LATEST badge.

You never need to edit either page on the website.

## Removing or replacing an edition
Open the file in the **reports** folder, click the three-dot menu → **Delete file**, then upload the corrected PDF.
